# Paopao Android (WebView + Widget)

เปลือกแอป Android ที่ห่อเว็บใน `app/src/main/assets/` (index.html, css/, js/) พร้อม widget หน้าจอหลัก

## Build ใน GitHub
1. อัปโหลดทั้งโฟลเดอร์นี้ขึ้น repo (ให้ `settings.gradle.kts` อยู่ที่ราก)
2. แท็บ Actions → workflow "Build APK" จะรันเองเมื่อ push (หรือกด Run workflow)
3. รันเสร็จ → เลื่อนลงล่างสุด → Artifacts → `paopao-debug-apk` → แตกซิป → ติดตั้ง `app-debug.apk`
   (ต้องอนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก)

## Widget (4×3)
กดค้างหน้าจอหลัก → Widgets → Paopao · เปิดแอปอย่างน้อย 1 ครั้งก่อน
- แถวบน: หมวด 3 อัน (ตั้งเองในแอป: ตั้งค่า → จัดการรายรับ-รายจ่าย → "หมวดที่แสดงบน widget") แตะเพื่อเลือก
- ช่องจำนวนเงิน: widget พิมพ์ตรง ๆ ไม่ได้ (ข้อจำกัดของ Android) แตะแล้วเด้งหน้าต่างกรอก ยอดจะค้างบน widget
- "− ใช้" / "+ เติม": บันทึกทันทีด้วยยอดและหมวดที่เลือก (ถ้ายังไม่มียอดจะให้กรอกก่อน)
- ยอดใช้ได้วันนี้: สีปกติตามธีม → เหลือง เมื่อใช้ ≥ 80% ของงบวัน → แดง เมื่อเกินงบ (ปรับที่ `WARN` ใน `PaopaoWidget.kt`)
- รายการเข้าคิว `pending` แล้วเว็บดึงไปบันทึกจริง (ทันทีถ้าแอปเปิดอยู่)

## สำรองข้อมูล
ปุ่ม "☁️ สำรองข้อมูล" ในแอปเปิดหน้าต่างเลือกที่เก็บของระบบ เลือก Google Drive หรือโฟลเดอร์ในเครื่องได้ (`Bridge.exportFile`)

## ไฟล์สำคัญ
`Bridge.kt` = เมธอดที่เว็บเรียก (`window.Android`) · `PaopaoWidget.kt` = widget · `AmountActivity.kt` = หน้าต่างกรอกจำนวนเงินจาก widget
ถ้าแก้เว็บ ให้ก๊อปไฟล์ใหม่ทับใน `app/src/main/assets/`
